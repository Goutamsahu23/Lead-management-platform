# Task B — Inherit and improve (digitalheroesco.com)

Assessment and migration package for taking over a live, poorly structured customer-facing codebase **without** a big-bang rewrite.

Assumed starting problems (as specified):

- No automated tests  
- Business logic inside route handlers  
- Direct database calls from the frontend  
- Secrets in the repository  
- Real customers; downtime is unacceptable  

## Deliverables

| File | Contents |
|------|----------|
| [01-ASSESSMENT.md](01-ASSESSMENT.md) | What to fix, in what order, and risk of leaving each issue |
| [02-MIGRATION-PLAN.md](02-MIGRATION-PLAN.md) | Week 1 / Month 1 / Quarter 1 phased plan |
| [03-REFACTOR-DEMO.md](03-REFACTOR-DEMO.md) | Realistic before/after contact-lead refactor + commentary |
| [04-ENGINEERING-STANDARDS.md](04-ENGINEERING-STANDARDS.md) | Standards v1 and how to adopt them with a resistant team |
